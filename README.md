# Sistemas de gestión de usuarios

## Descripción y finalidad

El proyecto documenta las altas y bajas de usuarios, los permisos y las políticas de acceso. Su finalidad es que la persona responsable pueda consultar qué pasos seguir al crear o dar de baja una cuenta y qué criterios aplicar al asignar, revisar o retirar permisos.


## Objetivos

- Describir los procedimientos de alta y baja de cuentas de usuario.
- Documentar los criterios para asignar, revisar y retirar permisos.
- Recoger las políticas de acceso aplicables a las cuentas de usuario.
- Mantener el inventario del proyecto y registrar las incidencias relacionadas con la gestión de usuarios.

```text

│   └── requisitos.txt
├── incidencias/
│   └── incidencias.txt
├── .gitignore
└── README.md
```

## Descripción de los principales archivos

| Archivo | Función |
| --- | --- |
| `datos/inventario.txt` | Reúne el inventario del proyecto. |
| `documentacion/introduccion.txt` | Presenta el proyecto y el ámbito de la gestión de usuarios que abarca. |
| `documentacion/procedimientos.txt` | Sirve de guía para las altas, las bajas y los cambios de permisos. |
| `documentacion/requisitos.txt` | Recoge los requisitos que deben considerarse en la gestión de usuarios y accesos. |
| `incidencias/incidencias.txt` | Permite registrar y consultar incidencias relacionadas con las cuentas y sus permisos. |
| `.gitignore` | Define los patrones de archivos y carpetas que Git debe ignorar. |
| `README.md` | Presenta el proyecto, sus objetivos y la organización de sus archivos. |
